# 📇 KeepContact

## 📌 Contexte
Le problème que ce projet cherche à résoudre est la **gestion efficace des contacts**, permettant aux utilisateurs d'**ajouter, modifier et consulter** les informations relatives à leurs contacts.

## 🎯 Objectif
L'objectif principal de ce projet est de fournir une **interface simple et fonctionnelle** pour gérer les contacts, tout en respectant les **bonnes pratiques de développement** avec Symfony.

## 🛠️ Technologies utilisées
- **Backend :** Symfony (PHP) – framework robuste et flexible.
- **Base de données :** MySQL – pour stocker les informations des contacts.
- **Frontend :** Twig (moteur de templates de Symfony), CSS et Bootstrap – pour un design agréable et responsive.

## 🚀 Fonctionnalités
- 🔹 **Inscription et connexion** des utilisateurs.
- 🔹 **Ajout** d'un contact (nom, prénom, email, numéro de téléphone).
- 🔹 **Modification** des informations d'un contact existant.
- 🔹 **Suppression** d'un contact.
- 🔹 **Recherche** d'un contact par son nom.
- 🔹 **Déconnexion** de l'utilisateur.

## 🖥️ Démonstration
1. Page de connexion permettant aux utilisateurs de s'authentifier.
2. Page d'inscription pour créer un compte.
3. Tableau de bord affichant la liste des contacts.
4. Actions possibles : Ajouter, Modifier, Supprimer, Rechercher un contact.
